# ATS Resume Analyzer

A web-based resume analysis tool that compares a candidate's resume with a job description and provides actionable feedback to improve job relevance, keyword coverage, and resume presentation.

## Overview

The ATS Resume Analyzer helps job seekers understand how closely their resume aligns with a target job description. It extracts text from uploaded PDF and DOCX files, identifies relevant skills and requirements, and generates a structured review with improvement suggestions.

## Features

- **Resume Upload:** Supports PDF and DOCX files up to 5 MB.
- **Job Description Analysis:** Identifies recognized skills and requirements from the provided job description.
- **Keyword Matching:** Compares job requirements against resume content and highlights matched and missing keywords.
- **Required vs. Preferred Skills:** Categorizes detected requirements based on job description wording.
- **Recruiter-Style Review:** Checks resume sections, measurable achievements, action-oriented bullet points, contact details, and professional links.
- **Match Score:** Calculates an explainable, rule-based score using detected job requirements and resume structure.
- **Actionable Recommendations:** Suggests areas where the resume could better demonstrate relevant qualifications and experience.
- **Report Export:** Allows users to download their analysis as a JSON file.
- **Responsive Interface:** Provides a clean interface built with HTML, CSS, and JavaScript.

## Getting Started

### Prerequisites

- Python 3.10 or later
- pip
- Git (optional, for version control)

Node.js is not required.

### Installation on Windows

1. Clone the repository:

```powershell
git clone https://github.com/SimranJaiswal/clearcv-ats-resume-analyzer.git
cd clearcv-ats-resume-analyzer
```

2. Create a virtual environment:

```powershell
py -m venv .venv
```

3. Install dependencies:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

4. Start the development server:

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --reload
```

5. Open the application:

http://127.0.0.1:8000

### Installation on macOS/Linux

1. Clone the repository:

```bash
git clone https://github.com/SimranJaiswal/clearcv-ats-resume-analyzer.git
cd clearcv-ats-resume-analyzer
```

2. Create a virtual environment and install dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

3. Start the server:

```bash
uvicorn backend.main:app --reload
```

4. Open http://127.0.0.1:8000 in your browser.

## How It Works

1. Upload a resume in PDF or DOCX format.
2. Paste the target job description.
3. Extract text from the uploaded document.
4. Identify supported skills and requirements in the job description.
5. Compare detected requirements with the extracted resume text.
6. Review the match score, missing requirements, resume feedback, and improvement suggestions.
7. Export the analysis report in JSON format.

## Scoring Methodology

The application uses a transparent heuristic rather than a proprietary ATS scoring algorithm.

- **Job requirement matching:** Measures how many detected requirements appear in the resume.
- **Resume structure:** Checks for common sections such as skills, education, experience, and projects.
- **Overall score:** Combines job requirement coverage and resume structure into a single illustrative score.

The score is intended to support resume improvement. It does not represent the score generated by any specific employer's ATS or predict interview selection.

## Current Limitations

- Keyword matching is based primarily on predefined skill terms and text patterns.
- Requirement priority classification depends on wording and may not capture every job description accurately.
- Missing keywords indicate that relevant evidence was not detected; they do not prove the candidate lacks that skill.
- Scanned or image-only PDFs may require OCR to extract text.
- Recruiter-style feedback uses predefined checks and is not a substitute for a human review.
- The application does not currently include user accounts, persistent analysis history, or an external AI service.

## Future Improvements

- Semantic matching for related skills and equivalent terminology.
- More accurate extraction of mandatory and preferred qualifications.
- AI-assisted feedback and resume bullet-point improvements.
- Downloadable PDF analysis reports.
- Resume history and user accounts.
- Automated tests and expanded support for complex resume layouts.

## Privacy

Uploaded documents are processed in memory by the application and are not intentionally stored by the application. Avoid uploading confidential documents to untrusted deployments. Production hosting should include appropriate file validation, access controls, retention policies, and privacy safeguards.
